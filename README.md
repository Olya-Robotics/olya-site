# OLYA Robotics - Site institucional

Site institucional da OLYA Robotics com solucoes em robotica educacional, incluindo braco robotico, kits de robotica e materiais de apoio para escolas e instituicoes de ensino.

## Principais conteudos
- Braco robotico educacional e especificacoes
- Kits de robotica para diferentes niveis
- Documentacao institucional e suporte
- Aplicacoes e metodologia STEAM

## Desenvolvimento local
```sh
npm install
npm run dev
```

## Build
```sh
npm run build
```

## Deploy
Recomendado via Vercel (Vite).
